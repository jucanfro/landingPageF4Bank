# F4Bank - Landing Page

## Sobre o Projeto

Este é um projeto simples de uma **Landing Page** criada para o **F4Bank**, um banco fictício inspirado em grandes bancos públicos brasileiros, desenvolvido com **JavaScript puro**, **Tailwind CSS** e **CSS personalizado**.  

A Landing Page serve como porta de entrada do banco, apresentando seus produtos, serviços e informações institucionais de forma clara, atraente e responsiva.

---

## Objetivo

O objetivo do projeto é construir uma página de apresentação do F4Bank, comunicando:

- Produtos principais
- Experiência visual moderna e responsiva, utilizando **Tailwind CSS** para estilização rápida e consistente.

---

## Tecnologias Utilizadas

- **HTML5** – Estrutura semântica da página  
- **CSS / Tailwind CSS** – Estilização e design responsivo  
- **JavaScript Puro** – Funcionalidades como carregamento de menu e footer
